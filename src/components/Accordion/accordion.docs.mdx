The Accordion component allows users to expand and collapse sections of related content.

This implementation uses:

- Native `<details>` / `<summary>`
- Single public class: `wmata-accordion`

---

## Usage

```html
<div class="wmata-accordion">
  <details>
    <summary>Lorem Ipsum Dolor</summary>
    <div>
      Vestibulum sed risus. Sed non aliquam turpis.
    </div>
  </details>

  <details>
    <summary>Lorem Ipsum Dolor</summary>
    <div>
      Pellentesque interdum sapien sit amet magna lobortis ultrices.
    </div>
  </details>
</div>
