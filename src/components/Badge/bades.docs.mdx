# WMATA Badges
Small status labels for tables, lists, and detail views.

Badges follow WMATA’s color rules and typography tokens and are ideal for showing
approval status, request state, or severity.

---

## Available Classes

| Class | Purpose |
|-------|---------|
| `.wmata-badge` | Base badge style (rounded pill) |
| `.wmata-badge-neutral` | Default / neutral status |
| `.wmata-badge-success` | Positive / completed / approved |
| `.wmata-badge-error` | Error / rejected / failed |
| `.wmata-badge-warning` | Warning / attention needed |
| `.wmata-badge-info` | Informational status |
| `.wmata-badge-chip` | **Internal app badge** (larger pill “chip”, optional icon) |
| `.wmata-badge-chip__icon` | Icon container inside the internal badge chip |

---

## How To Use (ServiceNow)

Use badges inside tables, cards, or detail panels.

### Example – in a table cell

```html
<td>
  <span class="wmata-badge wmata-badge-success">
    Approved
  </span>
</td>



---

## Internal Application Usage (Default Badge)

The base `.wmata-badge` class is designed for internal application usage.
It supports optional icons and uses the standard WMATA color palette.

### Without Icon

```html
<span class="wmata-badge">
  Lorem Ipsum
</span>
