# WMATA Badges  
Small status labels for tables, lists, and detail views.

Badges follow WMATA’s color rules and typography tokens and are ideal for showing
approval status, request state, or severity.

---

## Available Classes

| Class | Purpose |
|-------|---------|
| `.wmata-badge` | Base badge style (rounded pill) |
| `.wmata-badge-neutral` | Default / neutral status |
| `.wmata-badge-success` | Positive / completed / approved |
| `.wmata-badge-error` | Error / rejected / failed |
| `.wmata-badge-warning` | Warning / attention needed |
| `.wmata-badge-info` | Informational status |

---

## How To Use (ServiceNow)

Use badges inside tables, cards, or detail panels.

### Example – in a table cell

```html
<td>
  <span class="wmata-badge wmata-badge-success">
    Approved
  </span>
</td>




---

## Using Badges Inside a Card

Badges work especially well inside `.wmata-card` components to show the status
of a record (purchase request, approval, task, etc.).

### Example – Card Header with Status Badge

```html
<div class="wmata-card">
  <div class="wmata-card-header">
    <div style="display: flex; justify-content: space-between; align-items: center;">
      <div>
        <h2 class="wmata-page-title">Purchase Request #RITM0012345</h2>
        <p class="wmata-body-text">
          Laptop and accessories for new hire.
        </p>
      </div>

      <span class="wmata-badge wmata-badge-success">
        Approved
      </span>
    </div>
  </div>

  <div class="wmata-card-body">
    <div class="wmata-info-row">
      <div class="wmata-info-label">Requested By</div>
      <div class="wmata-info-value">Jane Doe</div>
    </div>
    <div class="wmata-info-row">
      <div class="wmata-info-label">Total Cost</div>
      <div class="wmata-info-value">$1,250.00</div>
    </div>
  </div>
</div>
