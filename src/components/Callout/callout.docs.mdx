# Callout

The **Callout** component is a focused action panel used to collect simple input (such as email subscription).

It is controlled by a **single base class** and optional **state modifier classes**.

---

## States Overview

| State      | Class Applied |
|------------|--------------|
| Default    | `.wmata-callout` |
| Error      | `.wmata-callout wmata-callout--error` |
| Completed  | `.wmata-callout wmata-callout--success` |

---
