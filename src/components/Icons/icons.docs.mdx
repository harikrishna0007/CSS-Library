# WMATA Icons  
Reusable icon styles for ServiceNow widgets, React components, and plain HTML.

Icons are provided as **PNG assets** and exposed via **CSS utility classes**.  
They are designed to visually align with WMATA signage and UI patterns.

## Available Classes

| Class | Purpose |
|------|---------|
| `.wmata-icon` | Base icon styling |
| `.wmata-icon--bus` | Bus icon |
| `.wmata-icon--rail` | Rail icon |
| `.wmata-icon--wheelchair` | Accessibility / wheelchair |
| `.wmata-icon--escalator` | Escalator |
| `.wmata-icon--airplane` | Airport / flight |
| `.wmata-icon--arrow-right` | Directional arrow |
| `.wmata-icon--no-entry` | No entry / restricted |
| `.wmata-icon--elevator` | Elevator |
| `.wmata-icon--sm` | Small size |
| `.wmata-icon--md` | Medium size (default) |
| `.wmata-icon--lg` | Large size |
| `.wmata-icon--xl` | Extra large size |

---

## How To Use (ServiceNow)

Icons are rendered using a `<span>` element with the appropriate CSS classes.

```html
<span class="wmata-icon wmata-icon--bus wmata-icon--md" aria-label="Bus"></span>
<span class="wmata-icon wmata-icon--elevator wmata-icon--lg" aria-label="Elevator"></span>


<button class="wmata-btn wmata-btn-primary">
  <span class="wmata-icon wmata-icon--arrow-right wmata-icon--sm"></span>
  Continue
</button>
