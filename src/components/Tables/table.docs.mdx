# WMATA Tables  
Reusable table styles for ServiceNow widgets, React components, and plain HTML.

Tables are designed for dense operational data (attendance, approvals, assets) with clear headers, spacing, and hover states.

---

## Available Classes
---

# Class Reference

Below are the required and optional classes for the WMATA Table component.

---

## Required Classes

| Class | Description |
|-------|------------|
| `wmata-table-wrap` | Required wrapper for responsive behavior |
| `wmata-table` | Base table class |

---

## Header Classes

| Class | Description |
|-------|------------|
| `wmata-table__header` | Base header cell styling (apply to `<th>`) |
| `wmata-table__header--sm` | Small header variant |
| `wmata-table__header--lg` | Large header variant |
| `wmata-table__header-icon` | Wrapper for header content with icon |
| `wmata-table__icon` | Icon slot inside header |

---

## Cell Classes

| Class | Description |
|-------|------------|
| `wmata-table__cell--double` | Container for double-text cell layout |
| `wmata-table__cell-primary` | Primary cell content |
| `wmata-table__cell-secondary` | Emphasized cell content |

---

## Table Modifiers

| Class | Description |
|-------|------------|
| `wmata-table--striped` | Adds zebra striping |
| `wmata-table--hover` | Adds hover row state |
| `wmata-table--compact` | Reduces cell padding |
| `wmata-table--sticky` | Enables sticky header |
| `wmata-table--stack` | Enables responsive stacking on mobile |

---

# Responsive Requirement

When using `wmata-table--stack`, each `<td>` must include:

```html
<td data-label="Header Name">Value</td>

## How To Use (ServiceNow)

```html
<div class="wmata-table-wrap">
  <table class="wmata-table">
    <thead>
      <tr>
        <th scope="col" class="wmata-table__header wmata-table__header--sm">Header</th>
        <th scope="col" class="wmata-table__header wmata-table__header--sm">Header</th>
        <th scope="col" class="wmata-table__header wmata-table__header--sm">Header</th>
        <th scope="col" class="wmata-table__header wmata-table__header--sm">Header</th>
      </tr>
    </thead>

    <tbody>
      <tr>
        <td>Data Cell</td>
        <td>Data Cell</td>
        <td>Data Cell</td>
        <td>Data Cell</td>
      </tr>
      <tr>
        <td>Data Cell</td>
        <td>Data Cell</td>
        <td>Data Cell</td>
        <td>Data Cell</td>
      </tr>
    </tbody>
  </table>
</div>
