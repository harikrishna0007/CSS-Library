# WMATA Buttons  
Reusable button styles for ServiceNow, React, and plain HTML.

Buttons follow WMATA’s color rules and typography tokens.

---

## Available Classes

| Class | Usage |
|-------|--------|
| `.wmata-btn` | Base button class |
| `.wmata-btn-primary` | Primary action button |
| `.wmata-btn-secondary` | Secondary button |
| `.wmata-btn-accent` | Accent / attention button |
| `.wmata-btn-primaryv2` | Dark-blue primary |
| `.wmata-btn-secondaryv2` | Outlined secondary |

---

## Variants

| Variant | Class |
|--------|------|
| Primary | `.wmata-btn-primary` |
| Secondary | `.wmata-btn-secondary` |
| Accent (Blue) | `.wmata-btn-accent` |
| Primary v2 (Dark Blue) | `.wmata-btn-primaryv2` |
| Secondary v2 (Outline Blue) | `.wmata-btn-secondaryv2` |
| Inverse Primary | `.wmata-btn-inverse-primary` |
| Inverse Secondary | `.wmata-btn-inverse-secondary` |

---

## Sizes

- Large: `.wmata-btn-lg`
- Small: `.wmata-btn-sm`
- Icon-only: `.wmata-btn-icon`

---

## Usage (ServiceNow / HTML)

```html
<button class="wmata-btn wmata-btn-primary wmata-btn-lg">Submit</button>
<button class="wmata-btn wmata-btn-secondary wmata-btn-lg">Cancel</button>
