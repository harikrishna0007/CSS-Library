# WMATA Typography

WMATA typography follows the Helvetica Now family and maintains consistent sizing across ServiceNow and React apps.

---

## 📌 Available Classes

| Class | Purpose |
|-------|---------|
| `.wmata-h1` | Large section headings |
| `.wmata-h2` | Subheadings |
| `.wmata-body` | Standard body text |
| `.wmata-caption` | Small helper or description text |

---

## How to Use (ServiceNow)

```html
<h1 class="wmata-h1">Metro System Updates</h1>
<h2 class="wmata-h2">Service Changes</h2>

<p class="wmata-body">
  The Red Line will experience delays due to scheduled maintenance.
</p>

<p class="wmata-caption">Updated 2 hours ago</p>
